### 🎯 درباره پروژه

این پروژه یک پلتفرم جامع مدیریت آموزشی است که از قابلیت‌های هوش مصنوعی برای بهبود تجربه یادگیری استفاده می‌کند. سیستم شامل چت هوشمند، مدیریت گروه‌های آموزشی و پنل مدیریتی پیشرفته است.

## ✨ ویژگی‌های اصلی

### 🤖 چت هوشمند
- پشتیبانی از نقش‌های مختلف (دانش‌آموز، معلم)
- اتصال به مدل‌های زبانی بزرگ (LLM) از طریق OpenRouter
- پشتیبانی از WebSocket برای ارتباط Real-time
- سیستم استریمینگ پاسخ‌ها

### 👥 مدیریت کاربران و گروه‌ها
- سیستم احراز هویت با JWT
- مدیریت نقش‌ها (Admin، User)
- ایجاد و مدیریت گروه‌های آموزشی
- تخصیص دانش‌آموزان به گروه‌ها

### ⚙️ تنظیمات پیشرفته
- مدیریت تنظیمات LLM از پنل ادمین
- ذخیره API Key در دیتابیس
- پیکربندی مدل‌ها و پارامترها

### 📊 پنل مدیریتی
- داشبورد جامع برای ادمین
- نمایش آمار و گزارش‌ها
- مدیریت کاربران و دسترسی‌ها

اولین ثبت نام شما به عنوان ادمین خواهد بود
1. وارد پنل ادمین شوید
2. به بخش "تنظیمات" بروید
3. اطلاعات زیر را وارد کنید:
   - **Base URL**: `https://openrouter.ai/api/v1`
   - **Model Name**: مدل دلخواه را انتخاب کنید
   - **API Key**: کلید API خود از OpenRouter

## 🔌 API Endpoints

### احراز هویت
- `POST /auth/register` - ثبت‌نام کاربر جدید
- `POST /auth/login` - ورود به سیستم
- `GET /auth/me` - اطلاعات کاربر جاری

### گروه‌ها
- `GET /groups` - لیست گروه‌ها
- `POST /admin/groups` - ایجاد گروه جدید
- `GET /groups/{id}` - جزئیات گروه
- `POST /admin/groups/{id}/students/{user_id}` - اضافه کردن دانش‌آموز

### چت
- `WS /ws/chat/{role}` - اتصال WebSocket برای چت

### تنظیمات
- `GET /admin/llm-settings` - دریافت تنظیمات
- `POST /admin/llm-settings` - ذخیره تنظیمات

## 🐛 عیب‌یابی

### مشکل: WebSocket قطع می‌شود

**علت**: مشکل در اتصال شبکه یا پیکربندی

**راه‌حل**:
1. لاگ‌های Backend را بررسی کنید
2. Firewall را چک کنید
3. از CORS صحیح اطمینان حاصل کنید

### مشکل: خطای 401 Unauthorized

**علت**: JWT Token نامعتبر یا منقضی شده

**راه‌حل**:
1. مجدداً لاگین کنید
2. Token را بررسی کنید
3. تاریخ انقضای Token را چک کنید

### مشکل: چت پاسخ نمی‌دهد

**علت**: مشکل در اتصال به LLM Provider یا API Key نامعتبر

**راه‌حل**:
1. API Key را در پنل ادمین بررسی کنید
2. Backend را Restart کنید
3. صحت API Key را در OpenRouter چک کنید

## 🔒 امنیت

- همه API Key ها در دیتابیس ذخیره می‌شوند (نه در کد)
- از JWT برای احراز هویت استفاده می‌شود
- رمزهای عبور با bcrypt هش می‌شوند
- CORS برای جلوگیری از دسترسی غیرمجاز تنظیم شده
- Endpoint های ادمین محافظت شده‌اند
